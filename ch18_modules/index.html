Export & Import

Explore how JavaScript modules share functions, variables, and classes between different files.

📦

1. Export

A module makes code available to other files using the export keyword. 

// math.js

export const PI = 3.14159;

export function add(a, b) {
  return a + b;
}
📥

2. Import

Another module receives exported code using the import keyword. 

// app.js

import { PI, add } from "./math.js";

console.log(PI);
console.log(add(10, 5));

KEY CONCEPTS

What You Should Remember

01

Named Export

export function add() {}

Import it using its exact exported name.

02

Named Import

import { add } from "./math.js"

Use curly braces for named exports.

03

Default Export

export default User

A module can have one default export.

04

Module Script

<script type="module">

This tells the browser to treat the file as a module.
